Inventory Recommendation System Using Historical Pharmaceutical Sales Data: Developed a data-driven inventory recommendation system using five years of historical pharmaceutical sales data. Performed data cleaning and preprocessing, exploratory data analysis, feature engineering, and visualization using Python, Pandas, NumPy, Matplotlib, and Seaborn. Implemented and compared Linear Regression, Decision Tree Regression, and Random Forest Regression models using Scikit-learn, evaluating performance with MAE, RMSE, and R². Linear Regression achieved an R² of approximately 0.86 and was selected as the final model for predicting pharmaceutical demand and supporting inventory planning decisions.
